A few things I've built, or am still building.

01. Custom Vulkan Renderer

May 2026 – present | C++, Vulkan, Slang, GLFW, CMake

I'm building a renderer from scratch to learn more about real-time graphics and low-level GPU programming.

So far: a dynamic-rendering pipeline, vertex and index buffers, descriptor sets, frame synchronization, and shader compilation through CMake. I'm also integrating Vulkan-Hpp RAII wrappers for resource management.

» Browse the code

02. VimAnywhere

September 2026 | Swift, SwiftUI, AppKit, CoreGraphics

Vim-style navigation and editing in text fields across macOS applications. An early prototype, with Normal and Insert modes and multi-key commands like dd, dw, and gg.

It uses keyboard event taps and the Accessibility API to figure out which text field is focused, while keeping normal macOS Command shortcuts working.

» Browse the code

03. Rabbit Hole

October 2026 | Wacode Hackathon · team project

A learning platform I co-developed with a team: diagnostic assessments, concept roadmaps, lessons, and quizzes. We connected a Next.js frontend to Flask APIs, with SQLite storing accounts and progress.

React Flow handles the visual roadmaps. Server-side grading and prerequisites determine which concepts unlock next.

Built with TypeScript, Next.js, React Flow, Python, Flask, and SQLite.
